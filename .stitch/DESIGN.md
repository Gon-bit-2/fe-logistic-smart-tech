# Design System: Emerald Logistics
**Project ID:** `15723199542215901690`

## 1. Visual Theme & Atmosphere
- Editorial logistics cockpit with an eco-tech tone: clean, breathable, and data-forward rather than dense dashboard chrome.
- Light-first surfaces with tonal layering instead of hard borders. Primary cards sit on pale mint backgrounds to create depth without boxed layouts.
- Floating elements use soft glassmorphism and green-tinted ambient shadows to feel high-end rather than corporate-generic.

## 2. Color Palette & Roles
- **Primary Action:** Emerald Depth `#006C49` for main CTAs, active states, and route emphasis.
- **Primary Accent:** Tech Mint `#10B981` for gradients, highlights, and eco-positive moments.
- **Secondary Support:** Forest Slate `#2B6954` and Mist Green `#ADEDD3` for calm supportive UI states.
- **Growth / Financial Accent:** Sky Ledger `#006591` with bright companion `#23ACF1` for checkout and commercial emphasis.
- **Base Surface:** Mint Haze `#F0FDF4`.
- **Raised Surface:** Pure White `#FFFFFF`.
- **Soft Section Surface:** `#EAF7EE` and `#E4F1E8`.
- **Text:** Deep Ink Green `#131E19`, muted copy `#3C4A42`, outline `#6C7A71`, soft divider `#BBCABF`.

## 3. Typography Rules
- Font family is **Inter** across headline, body, and label roles.
- Headings are bold to extra-bold with tight tracking.
- Metadata uses uppercase labels with wide tracking for a “scan-first” dashboard rhythm.
- Body copy stays compact and neutral to preserve legibility over decorative styling.

## 4. Component Stylings
- **Buttons:** 8px radius, bold text, gradient fills for primary CTAs, tonal solid fills for secondary actions.
- **Inputs:** Quiet resting state with low-contrast bottom border; focus lifts into clearer primary emphasis.
- **Cards:** Prefer tonal separation and soft green-tinted shadow `0 20px 40px -10px rgba(6, 78, 59, 0.08)`.
- **Status Chips:** Pill-shaped, soft containers, high-contrast labels for shipment state and eco indicators.

## 5. Layout Principles
- Split layouts are common for transactional flows: visual narrative on the left, focused form workspace on the right.
- Use generous whitespace and asymmetry; avoid over-packing cards with dense borders.
- Navigation bars stay slim, glassy, and low-noise so the page content carries hierarchy.
- Transaction pages suppress unnecessary chrome and keep the user in a guided linear path.
